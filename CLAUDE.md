# FinFinder.ai — Project Intelligence

## What This Is
FinFinder.ai helps surfers find the right surfboard fins using AI-powered recommendations.
Live at finfinder.ai. Hosted on Render.

## Tech Stack
- Python 3, Flask (app.py is the main application)
- HTML templates (Jinja2) in /templates
- Static assets flat in /static (no subfolders)
- Blog data stored in blog_posts.json (not a database)
- Deployed via Render (Procfile uses gunicorn)
- Blog cache: 5 minutes in memory (BLOG_CACHE_TTL = 300)

## Site Structure
- / — Homepage with Fin Finder Expert chat widget
- /recommender — AI fin recommendation tool
- /all-about-fins — Educational guide
- /fin-setups — Fin setup comparisons
- /fin-box-systems — FCS vs Futures etc.
- /longboard-fins — Longboard-specific guide
- /fin-sizing-guide — Sizing by weight/board/conditions
- /about — About page
- /finsights — Blog hub (grid layout, 3 columns desktop, 1 mobile)
- /finsights/<slug> — Individual blog posts
- /finsights?search= — Server-side blog search
- /sitemap.xml — Dynamic, includes all blog posts
- /llms.txt — AI/LLM discoverability endpoint
- /robots.txt — References llms.txt

## Blog System (Finsights)
- 14 posts as of Feb 2026
- Data: blog_posts.json as {"posts": [...]} array
- Content format: FULL HTML (not markdown)
- Categories (exactly 4): guides, tips, reviews, news
- Filter buttons in finsights.html match these 4 categories
- Client-side pagination: 6 posts per page
- Related posts: up to 3, same category, auto-generated by app.py
- Author: use "FinFinder Team" (standardize — was inconsistent)

## Blog Post JSON Fields (required for every post)
- slug, title, excerpt, content (HTML), category
- author ("FinFinder Team"), date ("Mon DD, YYYY"), date_published (ISO), date_modified (ISO)
- read_time (integer, minutes)
- featured_image (filename.webp in /static), featured_image_alt
- meta_description, tags (array)
- primary_keyword, secondary_keywords (array)
- faqs (array of {question, answer} — template supports this but no posts use it yet, NEW POSTS SHOULD)

## Images
- Format: WebP only
- Location: flat in /static/ (not in a subfolder)
- Blog cards: width="400" height="192", lazy loaded
- Post hero: width="1200" height="448", fetchpriority="high"
- Fallback: blue wave icon if no featured_image

## Code Conventions
- Never use em dashes (—) in any content
- Never use AI-sounding words: "delve", "landscape", "leverage", "unleash"
- Short paragraphs (2-4 sentences)
- All blog images must be WebP format
- Always check blog_posts.json before writing to avoid duplicate topics
- Commit after each completed task
